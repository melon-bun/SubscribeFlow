# 知流 0.5.1

本版加入笔记与 AI 总结，并统一为「静流」视觉风格。

- **留下点什么**：通用笔记、项目笔记与「在用／观望／放弃」判断；可选择不写笔记，保存后在独立笔记页浏览、检索和编辑。
- **按需 AI 总结**：独立选择服务、长度与语言，生成结果先进入可编辑草稿，保存后才成为正式笔记；保护等待期间的新输入。
- **全新界面**：浅色／深色纸面布局、优先级信号条、平台标识和可关闭的轻科幻特效；品牌 logo 恢复白底原图。
- **分段切换动画**：平台筛选和模式页签的选中底色平滑滑动，尊重系统减少动态效果设置。
- **交互稳定性**：修复渠道筛选时的骨架闪烁、栏宽／高度跳变，以及内容总览、渠道、标签和笔记的侧栏高亮闪烁；完善长文字与短窗口显示。
- **README 与截图**：按当前功能重写更新说明，重新截取收件箱、深色主题、笔记、日历、看板、标签、渠道和链接收录八张界面图。

安装包为 **macOS Intel（x64）**，内置 Electron 与 Python 运行环境。退出旧版后替换 `.app`；升级前建议备份本地数据目录。

AI 功能可选，需要自行配置可用服务。详情读数中标为「示例数据」的部分仍为视觉样例。
安装包采用本机 ad-hoc 签名，未经过 Apple 公证；首次启动的 macOS 提示与此前版本相同。
