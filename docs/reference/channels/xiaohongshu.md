# 小红书渠道实施与验收

更新：2026-10-24（Asia/Tokyo）。支持作者订阅与单条链接收录；0.5.2 增加本地封面截图与原文链接限宽，已本地打包并验收，未推送。下方历史记录按各自日期理解。

## 接入与替换边界

Python `channels/xiaohongshu/adapter.py` 实现标准 ChannelAdapter，仅依赖注入的桥接、contracts 和资源协调，不访问数据库／界面。Electron 的 session、API、页面提取及时间解析独立存放；ChannelSessions 按渠道路由。Core 传递稳定来源、完整收录 ID、预算和不透明游标，保存标准 ContentItem；替换后端不改变来源／笔记身份与人工整理。

作者键 `xiaohongshu:author:<24位作者ID>`，内容键 `xiaohongshu:note:<24位笔记ID>`。分享 token 不参与身份或去重，不能把不同签名地址当作不同内容。Adapter 版本 4、parser 版本 3、进度版本 `xhs-page-3`；遇到旧游标显式重试。

## 登录、搜索与添加

- Electron 独立 `persist:xiaohongshu` 分区，与 B站和 Renderer 分开；不导入 Chrome Cookie，不依赖 OpenCLI／CDP。隐藏页面保留正常布局尺寸、沙箱和上下文隔离，无 Node 或应用 Preload。
- 首次使用／掉线打开官方应用内登录窗口。完成后关闭窗口，保存会话、检查连接，再重试。后台任务遇到登录／访问验证立即停止，不连续弹窗。
- 添加来源通过 **渠道按钮** 切换 B站／小红书；小红书输入昵称搜索，返回稳定作者 ID、名称、头像与公开描述。账号可能同名，用户选择并勾选确认后才订阅。
- **小红书搜索上限 60 秒**。搜索期间添加对话框所有按钮和输入禁用，包括渠道切换、解析、搜索、登录、检查、候选选择、确认、取消与关闭；Escape 和点击遮罩也不能提前关闭。成功／失败／超时后恢复原状态；迟到结果不能覆盖后续操作。其他渠道沿用各自采集实现。

## 详情读取与分享链接

主页只用于发现笔记 ID 和取得临时导航签名；完整入库记录跳过重复详情。未完整、读取失败或缺少有效分享链接的笔记保留重试机会。置顶和乱序不能以窗口内第一条旧 ID 判定结束；达到检查条数上限即停止，不向窗口外补位。

读取笔记详情并核对笔记／作者身份后，在该详情页执行 **分享 → 复制链接**，从站点生成的分享文本提取官方地址。保存完整的 `https://www.xiaohongshu.com/discovery/item/<笔记ID>?source=webshare&...&xsec_token=...&xsec_source=pc_share`，保留参数和编码。不会自行拼接 token，也不把主页的 pc_user 导航签名当成分享签名。

校验 HTTPS、官方主机、笔记 ID、一组非空 xsec_token、source=webshare、xsec_source=pc_share，无凭据、端口或片段。失败按条目错误保留，不能保存无签名地址并标记完整。ContentItem.url 与补充详情 ContentPatch.url 使用分享地址；通用 Repository 保存标准字段，不解析平台参数。主页临时签名仍只在后端缓存；分享地址可进入内容存储／外部打开，但 token 不写诊断日志或验证报告。

复制操作在页面范围拦截 writeText／write／execCommand 的待复制文本，结束或失败恢复方法；不读取、改写用户系统剪贴板，不发送给任何联系人。分享生成的 token 仍可能受网站规则或时效限制，不承诺永久可用。

用户明确要求暂不处理旧笔记兼容：已删除 **runtime/xiaohongshu-acceptance/** 中原 4 条小红书笔记，保留订阅、登录与历史任务；未操作日常数据目录。用户自行重新采集。本轮真实分享验证只读取页面，不重新入库。

## 预算、进度与日期

默认刷新检查主页前 8 条、回溯检查前 30 条；已有采集条数设置 1–50 限制本轮不同笔记检查数，自动／手动一致。已完整收录的笔记占一个名额，但不读取详情；失败的详情也不向窗口外补足。例如设为 5，3 条已收录只读另外 2 条详情，5 条都已收录则详情访问 0，不检查第 6 条补位。首屏加最多 12 次滚动，连续 3 次无新 ID 或发现 500 条结束扫描；完整 ID 预筛选最多 2000 条。导航间隔 9–13 秒，单次读取 20 秒，搜索私有请求最多 60 秒、其他请求最多 45 秒，扫描缓存 10 分钟。

每次结果是一个主页步骤或一条详情，Core 逐次提交。记录 profile_reads、discovered（窗口内检查的不同 ID 数）、skipped、detail_requests。标准 budget_unit=items，Core 按已跳过 + 成功／失败详情计量，不识别平台名；主页阶段只为未知笔记排队，详情仍逐条提交。取消、超时、登录／验证中止保留已提交内容。未知日期保留原始标签，不根据 ID 或更新时间编造发布时间；详情补充不能降低已保存日期精度。人工标签、处理状态与优先级保留。

始终声明 full_history=false，有界扫描成功仅表示读取窗口。预算耗尽、无新增、短列表或空列表不能当作全部历史完成。
