## 完整包内验收

实际 `.app` 复制到项目外临时目录，经 LaunchServices 前台启动；采用独立临时数据、最小 PATH 和故意无效的外部 Python 设置。安装包自带 Core 正常工作，退出码 0，`packagedSmoke=passed`。

新增冻结 Core 验收先生成隔离 v15 微信旧库，再由**包内二进制**执行升级：

- 两个旧微信来源／重复文章合为一篇、一个来源，只有一个公开 Adapter 与默认连接。
- 原人工正文与较新笔记保留，首次收录仍为原订阅采集；原值进入本机迁移档案，外键检查通过。

- 无付费密钥也可人工添加；同文返回已存在，新篇正常保存，重启后保持。清资料缓存后持久 gh_id 绑定仍在。
- v15→v16 升级前备份存在。原通用 v2→v16 升级、备份、互斥整理状态检查同样通过。
