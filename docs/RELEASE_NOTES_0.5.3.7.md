# 知流 0.5.3.7

本次发布包含 0.5.1 以来的本地更新。

- 修复内容总览中点击快捷筛选会跳回收件箱的问题；日历和优先级看板保持当前视图，并直接应用筛选。
- 阅读状态默认显示为「还会再看」「稍后阅读」「看完了」；可在「设置 → 通用」自定义前后两项名称。
- 修复标签较多时筛选面板无法下滑的问题，包括窄窗口展开详情的情况。
- 微信公众号人工收录与付费订阅统一到同一渠道，重复文章共用身份；升级旧数据时保留整理状态和笔记，并创建备份。
- 优化笔记操作区和后台刷新体验，检查间隔支持最长 144 小时。

## 下载与安装

下载并解压 `Subscribe-Flow-0.5.3.7-mac-x64.zip`，退出旧版后打开「Subscribe Flow.app」。本包适用于 macOS Intel，内置运行环境，无需另装 Node.js 或 Python。

本包使用本机签名，尚未经过 Apple 公证。首次打开如被阻止，可在「系统设置 → 隐私与安全性」中允许打开。`SHA-256` 文件可用于校验下载完整性。

微信公众号订阅使用第三方付费 API，可能产生费用；人工收录公众号文章无需该付费密钥。
