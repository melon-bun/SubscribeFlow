# 标签列表窄窗工具栏修正

用户反馈缩小屏幕时标签页顶部标题与筛选区域变宽。Codex 直接复现并修复，未派 MiniMax。基线 `947975d`，统一问题编号 [BUG-141](../../BUG_FIXES.md)。

正式 Renderer 加载隔离离线标签样本，在真实 Electron 窗口中依次调整尺寸；未使用日常数据库或凭据。

## 修正

原标题与工具组嵌套换行，缩窄后最多分成三行；切换两栏／堆叠与侧栏断点时又改变行数。现在标题与新建按钮一行、搜索／排序／状态筛选一行。搜索框最多 260 像素，根据可用列宽收缩，标签工具栏的局部布局不再被通用面板规则覆盖。
