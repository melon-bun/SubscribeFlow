# 标签管理 AI 自动识别页滚动修正

用户明确无法下滑的是 AI 自动识别页。Codex 直接处理，产品基线 `89ba2b4`，问题统一为 [BUG-142](../../BUG_FIXES.md)。版本按用户指定为 **0.5.3.1**。

根因是主题层后加载的通用 `.panel { overflow:hidden }` 覆盖了 `.tags-ai` 纵向滚动。修复仅增加针对 `.tags-ai.scroll-y` 的纵向滚动优先级，不改模型配置、请求策略或标签列表结构。

正式 Renderer 使用隔离设置与 12 条离线任务，向真实 Electron 页面发送原生鼠标滚轮事件。仅测量 scrollHeight 或程序设置 scrollTop 无法发现 hidden 容器禁止用户滚动的问题，此前验收遗漏该行为。
